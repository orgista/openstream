# REA trial: Skip Intro and Next Episode in five reference apps (owner 2026-10-11)

The owner asked to use REA (github.com/morluto/rea) so that, when the owner asks for an app function, we can see how other
apps do it, and to try it on Netflix, the Apple TV app, Paramount+, Plex and Infuse. Read native/apple/AGENTS.md §4.2
first (setup, targets, rules) and load the `reverse-engineer-anything` skill.

## The question (one feature, all five apps)
How does each app handle **Skip Intro / Skip Recap / Skip Credits** and the **Next Episode (post-play) prompt**?
For each app answer, with evidence (class/function/string and where it lives):
1. Where the intro/credits times come from (server markers, chapters, local detection, a fixed offset).
2. When each prompt appears and disappears (start/end time, how long it stays, what hides it early).
3. The Next Episode countdown: when it starts (credits marker? N seconds before the end?), its length, what happens
   at zero, what the remote/keys do, and how it changes for the last episode / a movie.
4. Settings the app exposes for it (auto-skip, autoplay next, "are you still watching" limits).
Say "not found" plainly where the evidence doesn't show it; never guess.
